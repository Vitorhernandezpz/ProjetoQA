# Laboratório de qualidade em Python

Comece pelo [laboratório 1 — comprar a última unidade](docs/01-estoque.md). Reserve até cinco horas para especificar, testar, provocar a falha e revisar a mudança.

| Entrega | Pergunta de qualidade |
| --- | --- |
| 1 · Estoque e pytest | Qual valor de entrada distingue uma compra válida de uma recusa indevida? |
| 2 · HTTP e SQLite | Uma falha ao gravar o pedido deixa o saldo consistente? |
| 3 · Gherkin e navegador | Quem compra a última unidade vê o saldo correto após recarregar? |
| 4 · Propriedades | Comprar e cancelar preserva o total de unidades? |
| 5 · OWASP | Um cliente consegue alterar o pedido de outra pessoa? |
| 6 · SonarQube e entrega | Que evidências justificam publicar o pacote testado? |

A primeira entrega contém a regra de domínio, testes unitários e o workflow inicial do GitHub Actions. As próximas serão trabalhadas em sequência.
